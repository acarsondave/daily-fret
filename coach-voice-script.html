Daily Fret — Coach Voice Script

Paste each line into any realistic text-to-speech tool, export the clip, and save it under the filename shown. Drop the folder into the app and the coach comes alive — no API keys, no cost.

How to use this

  1. Pick a free, natural-sounding TTS tool (suggestions below). Choose one voice and keep it consistent across every clip.
  2. For each line, hit Copy, paste into the tool, generate, and download as MP3.
  3. Save it using the filename shown next to the line (e.g. up-next-03.mp3).
  4. Put every clip in a folder named coach and drop it at daily-fret/public/coach/.
  5. Tell me they're in — I'll wire up the player (picks a fresh variant each time, no repeats inside a 14-session window) in one short pass.

You don't need every line to start — even 3–4 per section already feels alive. Fill the rest whenever.

Free tools that sound genuinely human

  • ElevenLabs free tier — the most expressive. ~10k characters/month free, which covers this whole script in one month. elevenlabs.io
  • Kokoro TTS (web) — open-source, unlimited, fully free, runs in your browser. Great natural quality. kokoroweb.app · HF demo
  • Microsoft Edge "Read Aloud" / Natural voices — surprisingly good and free (voices like "Aria", "Guy", "Jenny").

Voice direction: warm, calm, encouraging — a supportive coach, not a hype announcer. Steady pace, friendly. Pick a single voice and stick with it so every cue feels like the same person.

A note on drill names read me

Your drill names are whatever you type, so pre-made clips can't speak them. The coach uses name-free phrasing ("here's your next one") while the name stays on screen — this works for any routine.

Optionally, for your own recurring drills you can record their names too: save as name-<slug>.mp3 (e.g. name-spider-exercises.mp3) and I'll have the coach speak the name when a matching clip exists.
