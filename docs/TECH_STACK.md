# Tech Stack

- **Frontend**: React 19, TypeScript, Vite.
- **State Management**: Zustand (Local-first state, persisting to `localStorage`).
- **Styling**: Vanilla CSS, leveraging CSS Variables, Nesting, Container Queries.
- **Animations**: Framer Motion.
- **Icons**: Phosphor Icons (via `@phosphor-icons/react`).
- **Backend/Auth**: Firebase Auth & Firestore.
- **Deployment**: Cloudflare Pages (via Wrangler), auto-deployed from GitHub.
- **Domain**: `routines.minirecc.com`.
